# Figma verification record / Registro de verificación

`figma-state.json` records real node IDs, counts, prototype starting points and the final review of the Nora Design file. It is a local handoff ledger, not application state or an installer. The provisional offline importer was retired once the connected Figma workflow became available.

`figma-state.json` registra IDs reales, cantidades, puntos de inicio y revisión final del archivo de diseño de Nora. Es un registro local para el traspaso, no estado de la app ni un instalador. Se retiró el importador offline provisional al quedar operativo el flujo conectado de Figma.
